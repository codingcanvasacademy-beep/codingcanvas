# CodingCanvas — v1 Requirements

> **Core Value:** Get parents of young kids to trust CodingCanvas enough to book a free trial class.

---

## v1 Requirements

### Public Homepage (Marketing Site)

- [x] **HOME-01**: Visitor can see a professional hero section with a clear headline and "Book Free Class" CTA
- [x] **HOME-02**: Visitor can see "How It Works" section explaining the 3-step process (Discover → Try → Learn)
- [x] **HOME-03**: Visitor can see a Curriculum section explaining what kids learn and the learning path (Blocks → Python)
- [x] **HOME-04**: Visitor can see a Pricing section showing ₹2,000 / 8 classes with a free first class CTA
- [x] **HOME-05**: Visitor can see a Testimonials section with parent/student reviews
- [x] **HOME-06**: Visitor can see a "Meet the Teachers" section with names and credentials
- [x] **HOME-07**: Visitor can click a WhatsApp button/link to contact the academy directly
- [x] **HOME-08**: Visitor can see accurate social proof (no false "5,000+ students" claim)

### Navigation & Footer

- [x] **NAV-01**: Public navigation shows Curriculum, Pricing, and About links (not internal admin/portal links)
- [x] **NAV-02**: Admin portal link is removed from public-facing navigation
- [x] **NAV-03**: "Book Free Class" CTA button is visible and sticky in the navbar
- [x] **FOOT-01**: Footer contains correct links (Curriculum, Privacy, Contact/WhatsApp, Teacher Login)
- [x] **FOOT-02**: Footer copyright year is current and academy name is correct

### Free Trial Booking

- [x] **BOOK-01**: Parent can submit a free class booking form with name, child name, email, and phone
- [x] **BOOK-02**: Parent sees a confirmation message after successful booking submission
- [x] **BOOK-03**: Free class requests appear in the admin dashboard for the host to action

### SEO & Trust

- [x] **SEO-01**: Each page has a descriptive `<title>` tag and `<meta description>`
- [x] **SEO-02**: Homepage has a proper `og:image` for social sharing previews
- [x] **SEO-03**: Site uses semantic HTML (h1 → h2 → h3 hierarchy respected)

### Core Platform (Already Working — Preserve)

- [x] **PLAT-01**: Student can access Blockly sandbox and run drag-and-drop programs
- [x] **PLAT-02**: Student can access Python compiler and run real Python code
- [x] **PLAT-03**: Teacher can log in and access the teacher portal
- [x] **PLAT-04**: Admin can access the host/admin portal and manage requests + FAQs
- [x] **PLAT-05**: AI support chat is functional with host-injected FAQ knowledge

---

## Out of Scope

| Item | Reason |
|------|--------|
| Mobile app (iOS/Android) | Web-first launch; native app is a later milestone |
| Blog / content marketing | Too early; focus is conversion not discovery |
| Payment gateway (Stripe/Razorpay) | Manual class coordination acceptable at this scale |
| Student progress tracking / gamification | Separate milestone post-launch |
| Multi-language support | English-first for now |
| Email marketing / drip campaigns | Post-launch growth lever |
